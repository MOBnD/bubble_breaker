# LTデモ進行手順

## 基本方針

本番デモは、成功した録画を主に使用します。ライブ操作は「実際に触れる作品である」ことを示す補助に限定し、API通信やロード時間に発表全体を依存させません。

## 発表前チェックリスト

### 前日まで

- 30〜45秒の成功デモ動画を作成する。
- 動画には「入力→ダイブ→航行→バブル群→バブル詳細」の順を入れる。
- 航行中のブラックホール、経由地、モーションブラーが見える箇所を含める。
- 動画の最後にバブル群または詳細画面を2秒ほど止める。
- 動画にAPIキー、開発者ツール、個人情報を映さない。
- スライドのQRコードまたはURLを確認する。

### 当日会場で確認

- `dist/bb_proto4.html`をビルド済みであること。
- ローカルサーバーを起動済みであること。
- ブラウザでページを開き、WebGLが動作すること。
- 動画をローカル再生できること。
- スピーカー音量とBGM音量を確認する。
- 全画面表示にして、ブラウザの通知やタブを隠す。
- マウスカーソルを画面端へ移動する。
- 画面共有時に文字が読める解像度になっていること。
- スライドと動画を別ウィンドウで切り替えられること。

## 録画デモの編集順

### 0〜5秒：入力

- 入力画面を表示する。
- どんな意見を入力したかが読める時間を確保する。
- 「宇宙へダイブ」ボタンを押す直前で一瞬止める。

### 5〜18秒：ダイブと航行

- ブラックホールへ向かう航行を見せる。
- 経由地を回り込む場面を1か所入れる。
- モーションブラーが強く見える速度域を使う。
- 画面が暗転する直前まで引っ張らない。

### 18〜30秒：バブル群

- 宇宙からバブル群へ到達する変化を見せる。
- バブルの名前や分布が読める程度に止める。
- ここで「関連する意見のまとまり」と説明する。

### 30〜45秒：詳細化

- 1つのバブルへズームする。
- 分析または詳細画面を表示する。
- 出典や構成が見える場合は、1秒以上表示する。

## 本番の進行

### 録画を使う場合

1. スライド3で「ここから実際の体験を見せます」と言う。
2. 動画を再生する。
3. 動画中の説明は次の3文だけにする。

   > 入力した意見を起点に、情報の中へ入っていきます。
   > 
   > 関連する意見を、検索結果ではなく空間として見ています。
   > 
   > 最後に、気になったバブルを詳しく探索できます。

4. 動画終了後、すぐにスライド5へ進む。

### ライブ操作を追加する場合

録画終了後、時間に余裕がある場合だけ実施します。操作は次の中から1つに限定します。

- バブル群から1つのバブルへズームする。
- 設定パネルの速度線強度を変更する。
- 分析画面から詳細画面へ進む。

ライブでは作品の全工程を再現しません。録画と同じ結果になることも要求しません。

## 失敗時の切り替え手順

### APIロードが遅い

10秒以上進まない場合は、次のように言って録画へ切り替えます。

> 本番では通信状況に左右されるため、成功した航行の録画に切り替えます。

そのまま動画を再生し、技術トラブルの原因説明はしません。

### WebGLやブラウザ表示に問題がある

次の3枚を順に表示します。

1. `spec-assets/input-screen.jpg`
2. `spec-assets/bubble-group-screen.jpg`
3. `spec-assets/detail-screen.jpg`

説明文：

> 実際には、入力した意見がこのような宇宙空間を通って、関連するバブルの分析へつながります。

### ライブ操作を間違えた

操作を戻そうとせず、次の一言で録画またはスライドへ戻ります。

> いま見せたかった流れは録画で用意していますので、完成版をこちらでご覧ください。

### 音声が出ない

音声は作品の必須要素ではありません。BGMを止めたまま進行し、次の説明だけで補います。

> 音声も含めて宇宙へ入る演出にしていますが、今日は画面の変化を中心に見てください。

## 発表直前の30秒チェック

- スライド1を表示
- 動画ファイルを一度再生できることを確認
- ブラウザを全画面にする
- 音量を確認
- APIキーを画面に表示しない
- タイマーを5分に設定
- 画面共有範囲を確認
- 最後のまとめスライドを開いておく

## 5分を超えそうな場合の削除順

1. ライブ操作を削除する
2. スライド5の実装説明を1文にする
3. 想定質問の紹介を削除する
4. デモ後の説明を短くする

削除してはいけないものは、冒頭のフィルターバブルの問いかけ、録画デモ、最後のメッセージです。
