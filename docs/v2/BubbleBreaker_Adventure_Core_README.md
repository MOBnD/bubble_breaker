# BubbleBreaker Adventure Core — Codex Handoff

このフォルダは、別アカウントのCodexへ渡すための自己完結型ハンドオフです。

## 読む順番

1. `BubbleBreaker_Adventure_Core_Requirements.md`
2. `BubbleBreaker_Adventure_Core_Requirements.xlsx`
3. 既存BubbleBreakerのコードベース

## このプロジェクトの最重要変更

以前の方向性は「情報サイト + ファンタジーUI」に寄りすぎていました。

今回の仕様は、UIからではなく「冒険体験」から設計しています。

BubbleBreakerの本体は、カテゴリを移動することではありません。

**好奇心 → 接近 → 発見 → 意外なつながり → 世界の拡張 → 次の好奇心**

を繰り返すことです。

## 最初に実装するもの

「ゲーム」を出発地点にした最初の5分間のVertical Sliceだけです。

完全な推薦エンジン、ログイン、ランキング、育成、戦闘などは後回しにしてください。

## 既存コードについて

既存のカテゴリツリーやデータ構造は捨てず、可能なものは再利用してください。

ただし、カテゴリツリーそのものを新UIとして見せるのではなく、Adventure Experience Layerの裏側の知識グラフとして利用してください。

## 成功条件

「綺麗なファンタジーUI」ができたかではありません。

初見ユーザーが「次に何があるんだろう」と感じ、予想外の発見をし、その理由を理解し、さらに探索したくなるかどうかです。
