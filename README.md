# BubbleBreaker

SNSや検索サービスのおすすめだけでは見つけにくい視点を、話題のまわりから探検するWebプロトタイプです。気になることを入力すると、関連する話題・歴史・情報源・賛否を集め、バブルの宇宙として表示します。

## 起動する

リポジトリのルートでローカルWebサーバーを起動します。

```powershell
python -m http.server 8000 --directory src
```

ブラウザーで http://localhost:8000/index.html を開いてください。アプリ本体は src/index.html から直接読み込みます。ビルド手順や dist/ はありません。NGC 3324の背景画像は src/assets/、BGMは src/BGM/ から読み込みます。

初回はサービス紹介を読み、次にAPI Keyを設定します。入力した話題はOpenAIのWeb Searchで調査されます。使用モデルは gpt-6-luna です。

## 探索する

- 興味のあることを質問の例を参考に入力し、宇宙へダイブを選びます。
- 大きなバブルから小さな話題へ移動します。WASDで前後左右、E/Qで上下に動きます。画面のドラッグでも移動でき、Shiftを押すと速くなります。
- 個別のバブルを開くと説明を読み、概要・歴史・情報源・内外の論争を比べられます。各カードから根拠のリンクを確認できます。
- 今まで探索した世界から保存済みの探索を開けます。履歴はこのブラウザーのIndexedDBに保存されます。

## API Keyについて

このプロトタイプはブラウザーからOpenAI APIを直接呼び出します。API Keyは入力中にページのメモリだけで保持し、履歴やブラウザーの保存領域には記録しません。ただしブラウザーで使う以上、実行環境から完全には隠せません。個人用のキーを使い、共有サービスにする場合はキーをブラウザーへ渡さないバックエンドを用意してください。
