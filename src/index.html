BUBBLE BREAKER / SERVICE GUIDE

本来のインターネットを自由に旅する

ひとつの意見から、比較・反対・背景・意外な接続まで。情報を「答え」ではなく、根拠のある宇宙として探索するサービスです。

00 / MISSION

検索結果の列を、探索できる宇宙へ。

Bubble Breakerは、入力した意見を起点に三階層のバブル群を形成します。バブルを潜り、戻り、根拠を読み比べることで、自分の現在地と、まだ見えていなかった隣の世界を同じ地図の上で確かめられます。

01 / THE PROBLEM

フィルターバブルは、見えない境界線。

検索履歴や推薦は便利である一方、似た関心・似た立場を繰り返し提示しやすくします。問題は「誤った情報だけを見る」ことではなく、比較できたはずの情報が視界に入らず、世界の全体像を小さく捉えてしまうことです。

過去の選択→似た推薦→似た情報を閲覧→関心が固定↺

OpenAIの内部知識だけで詳細を作らず、先に検索経路と情報源を設計し、収集したEvidenceの範囲で整理・説明します。

03 / HOW BUBBLES FORM

単語ではなく、関係がバブルになる。

直接の対象だけでなく、比較対象、対立、文化・歴史、上位概念と下位概念を、入力との関連性を保ったまま配置します。

ROOT大きな情報環境社会・文化・制度などの全体像
contains
CENTRAL意味のまとまり比較・論争・文脈・主要テーマ
contains
LEAF具体的な論点個別の対象・事例・立場
04 / CONNECTION

なぜつながるかを残す

近い、隣接、遠い、意外な接続を区別し、完全なランダムではなく、Evidenceから後で説明できるつながりを提示します。

05 / TRANSPARENCY

説明と根拠を分離する

詳細では出典、主張の支持・矛盾、独立性、不確実性を保持します。confidenceは真実の確率ではなく、今回のEvidenceでの裏付け強度です。

06 / NAVIGATION

潜る、俯瞰する、戻る

親バブルの内側に下位世界が存在する三階層構造を、同じ宇宙の中で行き来します。酔いを抑える正面固定の2D表示も選べます。

07 / MEMORY

探索を持ち帰る

三階層のバブル群と生成済み詳細をローカル保存し、意見入力画面から過去の探索宇宙を復元できます。

08 / WHAT CHANGES

「与えられた答えを読む」から、
「情報環境を自分で旅する」へ。

Bubble Breakerは正解を一つに決める道具ではありません。自分の視界に何が入り、何が欠け、どの根拠がどの主張を支えているかを確かめながら、次の一歩を自分で選ぶための探索装置です。
